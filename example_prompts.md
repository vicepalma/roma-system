## Ejemplo para continuar donde quedamos

Para probar el nuevo flujo, en una próxima sesión podrías decirle a tu llm:

```txt
Lee AGENTS.md.

No recuerdo dónde quedamos.
Analiza ROADMAP.md, docs/tracking/ROMA_DEV_LOG.md y docs/work-items.
Dime el estado actual del proyecto y recomiéndame el próximo Work Item.
No implementes todavía.
```

Y cuando quieras implementar:

```txt
Lee AGENTS.md.

Work item:
ROMA-020

Implementa.
```
